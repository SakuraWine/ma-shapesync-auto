# MA Shape Sync Auto

Automatically sets up Modular Avatar **Blendshape Sync** on outfit meshes,
registering every blendshape that shares a name with the avatar body.

## Status

Work in progress.

## Requirements

- Unity 2022.3
- Modular Avatar
- VRChat Avatars SDK

## Usage

`Tools > SakuraWine > MA Shape Sync Auto`
